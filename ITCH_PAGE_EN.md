# itch.io page copy — UNFILED

**Title:** UNFILED — Interview Room 04

**Short description:** Press the witness. Challenge the evidence. Find the lie beneath the confession.

## Description

A witness admits part of the truth. The case should be over.

Then something else does not fit.

**UNFILED** is a dialogue-driven deduction game set in a spare, shadowy interview room. Question a witness, examine their statements and confront them with evidence. Each broken alibi reveals another layer of concealment.

### Two ways to investigate

- **Layers of Truth:** Three authored mysteries. Four layers of lies in every case. Press testimony, collect evidence and prove the contradictions.
- **Object in Mind:** A separate guessing game with twelve possible objects. Narrow down the answer through four replies: Yes, No, I think so, or I do not remember.

### Features

- English and Korean editions.
- Noir-inspired typography, muted colors and an evidence-notebook layout.
- Fixed solutions and evidence-based progress.
- Playable scripted demo without an API key.
- Optional AI conversation using your own Raon, OpenAI, Gemini, Claude, DeepSeek or compatible API key.

### Before downloading

This is an early **downloadable local web game**. It requires **Node.js 22.9+** and a modern browser. Extract the ZIP, run `start-en.cmd` on Windows and open the local address shown in the terminal. No package installation is needed.

AI access is optional and not included. Your provider may charge for use. The demo uses authored dialogue and recognizes a limited range of object questions. Progress lasts only while the local server session remains active; permanent saves are not yet supported.

All cases and characters are fictional. This is a mystery game, not psychological counseling.
