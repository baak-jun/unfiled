LOCAL / YOUR OWN KEY

Bring your own API key.

On Windows, run setup-key.cmd to choose a provider, model and key, then run start.cmd to start the game.

For manual setup, add the following settings to the .env file in the project folder.

AI_PROVIDER=raon
AI_MODEL=raon-1-mini-preview
AI_API_KEY=YOUR_API_KEY

Restart the server after changing the key. It is read by the local server and is not included in browser files or GitHub. In AI mode, questions and part of the transcript are sent to your selected AI provider.

Supported: Raon / OpenAI / Gemini / Claude / DeepSeek / OpenAI-compatible APIs. Provider usage charges and model access requirements apply. Restart the server after changing API settings.
